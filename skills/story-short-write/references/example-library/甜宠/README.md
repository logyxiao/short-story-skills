## 单篇卡片字段

- `导语摘要`：概括导语摆出的现场、人物关系、反差和悬念。
- `导语结构`：拆成“切入事件 → 身份/关系锚 → 冲突升级 → 尾钩”，供 Phase 1 检索。
- `故事梗概`：说透起因、关系推进、主要升级、反转和结局，检验导语承诺是否有足够正文可兑现。
- `可复用机制`：抽象到关系引擎、信息差或情绪兑现，不照搬原故事。
- `使用边界`：记录与项目硬约束冲突、逻辑较弱或容易同质化的部分，生成时必须避开。

## 使用原则

1. 先按用户要的时代、平台、关系引擎和情绪目标检索，不默认加载全库。
2. 每组新导语最多参考两张卡：一张取关系引擎，一张取导语结构；不能从同一张卡同时拿人物、职业、核心误会和结局。
3. 候选之间必须来自不同的关系引擎，不能把“网恋认错人”换四套姓名继续生成。
4. 卡片只提供已验证的结构证据；`story-constraints.md` 中的姓名、视角、主角主动、禁字和禁用剧情永远优先。
5. `索引.md` 的 A/B/C 是召回级别，不是文学质量评分；C 级卡只用于识别风险或研究抽象机制。
6. 新方案与任一卡在人物职业/高位身份、核心误会、关键物件、连续场景链、结尾兑现五项中重合三项时，判定为近似复刻，必须重做。
