# 番茄甜宠例文卡

## 《傲娇狐狸老公的打脸日常》

- 平台：番茄
- 原型定位：主动型毛绒控女主 × 隐藏富贵身份的九尾狐老板；先婚后爱、嘴硬反差、弹幕
- 导语摘要：女主旅行时摸尾、亲额头，次日便因异族规则与漂亮狐狸结婚。她把冷淡丈夫当成需要强取豪夺的对象，弹幕却在亲密现场揭穿：狐狸早已一见钟情，所有抗拒都是嘴硬。
- 导语结构：荒诞婚姻规则落地 → 女主主动建立亲密模式 → 男主态度与身体反应矛盾 → 弹幕揭露暗恋真相，并预告嘴硬会把甜文拖成遗憾。
- 故事梗概：祁沅看见弹幕后，决定停止主动亲近，逼白岐亲口承认感情。她撤回日常摸尾和约会，白岐立刻用早餐、露耳朵、在家锻炼等笨拙方式吸引她，却仍用反话否认。女主能与弹幕交流后，主动去猫咖沾上别的动物气味，又提起离婚，逐级击中狐狸的占有欲和被抛弃恐惧。白岐误以为她另有新欢，把她带回狐族住处，终于哭着承认爱意，还暴露自己是唯一九尾狐和公司老板。他其实早知女主喜欢毛茸茸，故意在旅行时现身缔约，也早已把财产交给她。女主说明冷落只是为了让他表达，两人重新确认唯一伴侣关系；白岐从傲娇狐狸变成公开黏人的丈夫。
- 可复用机制：女主“撤回稳定奖励”后，高位男主的真实需求立刻外显；身体反应与嘴上否认形成连续喜剧；宠物形态既是审美卖点，也是唯一伴侣承诺的实体符号；隐藏老板身份后置抬升资源位，但核心反转仍是他先动心。
- 使用边界：原文大量依赖强制亲密、囚禁、弹幕代讲内心及男主番外视角，不能进入新作。可学“主动女主训练嘴硬高位男主表达”，不能复制狐狸、弹幕、离婚刺激和锁链组合，也不能继承重复台词与露骨桥段。

## 《像这样的舔狗，我有两个》

- 平台：番茄
- 原型定位：强势漂亮女大学生 × 富家骄傲男大学生；伪兄妹、校园误会、救舔狗反成舔狗
- 导语摘要：女主带着从小依赖自己的弟弟入学，弟弟的室友误认他是被欺压的舔狗，扬言救兄弟脱离苦海。一个月后，室友穿着男仆装为女主打扫，声称兄弟当狗是自我贬低，自己当狗却是伟大爱情。
- 导语结构：先给出荒诞主仆关系 → 第三人站在道德高地介入 → 时间跳切展示改造失败 → 立场完全反转，用同一句“当狗”制造身份和情感钩子。
- 故事梗概：纪逾曾把前继母留下的儿子陈小野接回城里，为了让缺乏安全感的少年接受照顾，故意把家务包装成有报酬的交换，久而久之形成看似主仆、实为家人的依赖。大学里两人隐瞒姐弟关系，室友江砚池把纪逾误认成压榨陈小野的恋人，提出亲自替兄弟服务，以证明自己能解救他。纪逾顺势接招，给江砚池布置家务和陪伴任务；江砚池一面嘴硬地说在执行计划，一面沉迷于被她支配和认可。陈小野担心失去唯一家人，与江砚池争宠，纪逾则通过暂时拉开距离迫使两人正视各自诉求。陈小野交往后，江砚池又把他的恋情误解为背叛，穿男仆装上门告状，现场才揭开姐弟身份。纪逾主动选择江砚池，后来与他结婚，也给弟弟稳定的家人身份，三人的依恋分别落到爱情和亲情上。
- 可复用机制：“我要救舔狗”反转成“我自愿成为舔狗”；第三人对亲密关系的错误命名持续制造笑点；女主不解释而是接住挑战，用任务推动感情；同一份服务劳动先代表生存交换，后代表主动求爱。
- 使用边界：原文含扇打、羞辱式支配、恋足及伪骨科噱头，新作不得复刻；若用隐瞒亲缘，需让女主有现实理由且尽早埋入可验证细节，不能靠角色集体不问关系硬拖误会。

## 《妹妹真的不可以是我的吗？》

- 平台：番茄
- 原型定位：被收养的侠女妹妹 × 状元候选养兄；古言、青梅竹马、伪兄妹
- 导语摘要：侠女母亲从难民堆捡回女孩，直接塞给十岁儿子；少年误以为是小媳妇，被母亲打成“觊觎妹妹”的坏孩子。多年后，他反过来询问：没有血缘的妹妹，真的不能属于自己吗？
- 导语结构：捡孩子的高动作现场 → “媳妇/妹妹”标签当场冲突 → 十年养成被一句话压缩 → 成年后的同句反问翻转最初禁令。
- 故事梗概：楚悦颜在逃难中被亲生父母落下，被侠女收养并交给楚凌佑照顾。少年从喂饭、救她脱离黑屋到带她进入男学堂，把瘦弱女孩养成自由勇敢的姑娘，也因害怕失去而格外宠她。童年同窗宋煜用“小媳妇”羞辱两人，楚凌佑郑重强调她只是妹妹，这句话让悦颜记了十年。成年后，楚凌佑意识到感情变化，要求避嫌；悦颜误以为他嫌弃自己，又看见他代收别家小姐的香囊，主动答应与宋煜相看。宋煜真正目的却是报复楚凌佑，并当面揭穿养兄的暗恋。悦颜立即打断骗局，拉走楚凌佑；两人确认没有血缘，也承认彼此的占有与喜欢。父母其实早看出感情，顺势成全。楚凌佑高中状元后迎娶悦颜，童年“捡来的小媳妇”最终在双方选择下兑现。
- 可复用机制：一句童年定义成为成年关系的最大阻碍；家庭群像提供稳定、诙谐的宠爱底色；男主对“把她养胖”的执念源于失去妹妹的恐惧；女主主动相看和当场打人，迫使男主从克制转向表白。
- 使用边界：养兄妹题材天然有伦理争议，必须明确无血缘、成年后才转化感情，并保留女主独立选择。原文大量体罚、打斗和男主番外视角不宜继承；新作不可再用“捡回童养媳＋状元”整套配置。

## 《小狗捡到小猫后被赖上了》

- 平台：番茄
- 原型定位：天真善良的穷小狗妖 × 被遗弃、占有欲强的漂亮猫妖；双男主、同居、救助变绑定
- 导语摘要：小狗妖在雨夜捡回凶巴巴的小猫，分给他窝、罐头和毯子，以为猫咪霸占一切又不准自己交朋友只是天性。直到特殊时期，小猫把准备出门的小狗按回窝里，宣布捡了他就必须负责。
- 导语结构：雨夜救助建立情感债 → 用连续占领日常制造亲密喜剧 → 主角误把独占当物种习惯 → 特殊时期让小猫亲口定义恋爱关系。
- 故事梗概：刚化形的小土狗妖小圆在宠物店打工，雨夜把裴眠带回简陋住处。裴眠从借宿一天逐渐霸占窝、食物和抱枕，又会因小圆接触其他动物吃醋；小圆把这些都理解成猫的普通习惯，仍主动照顾、梳毛、陪玩。两人的身体距离不断缩短，小圆从网络和朋友提醒中意识到对方可能喜欢自己，直接询问并得到承认。裴眠的特殊时期让关系从暧昧变为伴侣；事后他因羞耻和被遗弃经历退缩，小圆则明确承诺愿意多打工、分享所有东西，连自己也交给他。此后裴眠不再遮掩占有欲。轮到小圆进入特殊时期时，裴眠赶回家照顾他，完成双向“捡回窝里”。结尾两人换成更大的共同住处，把开篇雨夜、毯子和“负责”转化为终身日常。
- 可复用机制：救助者以为自己单向给予，实际也被被救者建立归属；“猫都这样”反复遮蔽独一份偏爱；窝、毯子、饭碗等低成本物件持续记录关系升级；对被遗弃者而言，承诺的证明是每天回来而非盛大仪式。
- 使用边界：原文事件重复度高，主要靠萌宠互动和露骨亲密维持篇幅，缺少外部主线；只适合提取依恋机制和物件回扣。新作需增加一条清晰现实目标，且不能复制猫狗妖、特殊时期和宠物店组合。

## 《我是马屁精，可联姻老公是高需求宝宝啊》

- 平台：番茄
- 原型定位：靠夸人求生的替嫁女主 × 外表风流、需要高强度情绪价值的豪门继承人；联姻、婆媳宠爱、替嫁
- 导语摘要：女主幼年被家人卖掉，靠精准夸赞被富裕养父收留。成年后，养姐嫌弃联姻对象有情人而拒婚，女主主动接下婚约，笃定自己最擅长满足别人的情绪需求，能把竞争者挤出去。
- 导语结构：极端童年把“拍马屁”写成生存技能 → 成年婚约出现别人不要的高价值对象 → 女主主动替换位置 → 宣布用核心能力打赢情感竞争。
- 故事梗概：牛莱从小把察言观色和夸人练成求生本领，被暴发户家庭收养。养姐拒绝与豪门继承人宋一程结婚后，她为了安全和资源主动顶上。婚前她先赢得强势未来婆婆的喜爱，把真诚关注、即时赞美和服从规则变成进入豪门的能力。婚礼上，宋一程的情人怀孕闹场，他虽承认婚外关系，却明确把妻子和家族同盟放在公开位置；牛莱也不争浪漫名分，而是持续给他需要的肯定和家庭合作感。男主逐渐依赖她带来的高浓度关注，用财产、公开站队和家庭保护回应。女主原生家庭后来上门索取，婆婆与丈夫护住她；情人和原生家庭的支线相继退出。结尾女主同时拥有婚姻、孩子、婆家支持和财富，将童年讨好别人的求生术改造成主动经营关系的优势。
- 可复用机制：把通常被鄙视的性格缺点改写成女主可控的社交能力；宠爱来源不只男主，强势婆婆也能成为持续奖励；男主表面资源过剩，实际对稳定认可有高需求；“别人不要的联姻”因女主的策略成为她主动选择的上升通道。
- 使用边界：原文充斥金额计算、股份奖励、生育交换、警察与法律惩罚，也用贬低其他女性抬高女主，均与现行约束冲突。只能学习“情绪价值是一种主动能力”和婆家宠爱结构，不能检索其解决冲突或结局奖励方式。

## 《提分手后，高冷男大不装了》

- 平台：番茄
- 原型定位：突然有钱的年上男性 × 表面清冷贫困、后来创业成功的男大学生；双男主、包养误会、弹幕
- 导语摘要：主角拆迁后付钱与清冷男大学生恋爱。亲密过后，弹幕告诉他自己只是被利用的有钱配角：对方为祖母手术费接近他，不留宿和吃药都是因为厌恶。主角信以为真，当场把人赶走。
- 导语结构：用金钱关系快速建立不对等亲密 → 弹幕给出恶意剧情解读 → 日常细节被重新解释成嫌弃 → 主角立即撤回关系，把“他究竟爱不爱”变成主线。
- 故事梗概：主角接受弹幕判断，把宋炀的克制、借钱和不留宿都理解成利用，于是贬低关系并逐步抽身。宋炀却买衣服、主动留宿，也在祖母临终时把主角当成唯一依靠；祖母去世后，他恳求不要被丢下。弹幕仍说亲密只是宣泄，主角关闭提示，转而回避宋炀不断升级的靠近。朋友安排另一名年轻人后，宋炀第一次公开吃醋。体检最终揭开“吃药”的真实原因：他因只对主角产生过强身体反应而服用抑制剂，不留宿也是怕失控伤害对方。宋炀五年前就爱上曾帮助自己的主角，此后进入创业公司、做出成绩，并把共同住处作为长久承诺。两人从付费关系转为公开伴侣。
- 可复用机制：外部提示不是正确答案，而是把同一批事实解释成最伤人的版本；女主/主角撤回后，冷淡男方用行动暴露依赖；“因为厌恶所以避开”反转为“因为太渴望所以克制”；财富逆转放在感情揭晓之后，避免成功成为爱的凭证。
- 使用边界：原文含露骨身体设定、药物误会、弹幕及跨视角问答，新作不可照搬。若用外部信息误导，主角必须通过亲历事件主动验证，不能拖到体检一句话全盘解释；新角色姓名也必须避开禁用表。

## 《网恋加到死对头》

- 平台：番茄
- 原型定位：隐藏性别的强势集团掌权者 × 现实死对头兼网络黏人富少；双男主、网恋掉马、商战
- 导语摘要：主角又被死对头抢走项目，转头命令网恋对象报备。命令发出后，饭桌对面的死对头脸红并拍来同一套餐具；主角确认照片中的自己后，故意夸“对面的人”是理想型，看现实死对头如何吃自己的醋。
- 导语结构：现实竞争挫败 → 网络关系提供情绪出口 → 消息与对面动作同步完成掉马 → 主角不揭穿，立即用自恋式情敌刺激反击。
- 故事梗概：祁昭与许斯年从小竞争到接管公司，网络上却因一篇孤独求助帖相识。许斯年把匿名网友当唯一可信的人，逐渐成为爱报备、怕失去的黏人恋人；祁昭则隐瞒自己的真实性别和身份。庆功宴上发现掉马后，祁昭故意夸现实中的自己，逼许斯年露脸并加倍示爱。酒吧再遇时，两人各自看见对方靠近旁人，产生双向出轨误会。祁昭随后被同父异母弟弟用药算计，许斯年送医并认出网恋对象，却因怕被讨厌只敢用大号试探。祁昭夺回项目和公司位置后，认定许斯年另有新欢，主动拉黑分手。庆功宴露台，许斯年喊出网名、说明酒吧对象只是心理医生，也承认早已认出他。祁昭主动亲吻接回这只“小狗”，现实里的宿敌与网络上的唯一依靠终于合一。
- 可复用机制：同一人同时扮演情敌、死对头和恋人，任何吃醋都带双重喜剧；两个账号让高位男主在公事冷硬与私下缺爱之间切换；最初的匿名鼓励解释男主为何对主角形成长期依赖；主角发现真相后不揭穿，而是主动利用信息差反击。
- 使用边界：原文包含性别药物、夺权、送检、协会处理、暴力报复和较多露骨内容，不能进入受约束的新作。核心可迁移的是“一人三身份”和网络/现实性格反差，不得复制项目竞标、ABO和酒吧误会整套链条。

## 《老实人表妹》

- 平台：番茄
- 原型定位：伪装柔弱的主动侠女表妹 × 皇帝近臣兼冷面权臣；古言、身份伪装、女强男弱反差
- 导语摘要：自称老实人的寄居表妹暗恋冷面权臣，撞见他中毒后，主动把人带去后山“解毒”。男主醒来发誓追杀冒犯者；女主得知毒会按月发作，却因还有机会继续接近他而欣慰。
