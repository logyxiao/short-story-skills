# 知乎甜宠例文卡

## 《捡了室友不要的网恋男友后》

- 平台：知乎
- 原型定位：社恐女大学生 × 身份显赫的失眠症富家少爷；网恋、错认身份、室友冒领
- 导语摘要：室友把网恋对象按出手阔绰程度分类，月底批量删除。患有严重社交恐惧的女主为了练习与人交流，鼓起勇气询问能否把室友不要的男友分给自己一个。
- 导语结构：室友荒诞行为建立反差 → 女主暴露迫切但隐秘的需求 → “捡一个男友”主动选择 → 被丢弃对象究竟是谁的身份钩子。
- 故事梗概：女主姜灯灯花钱买下室友姚曦月弃用的社交账号，把从不回复的联系人当树洞，连续三个月分享生活。对方江牧野因失眠逐渐依赖她的消息和睡前故事，以高额报酬留住她，随后主动确认网恋关系。两人曾在线下擦肩而过，江牧野却因女主拿错室友的书，把她误认成姚曦月；机场见面时女主又戴着口罩，使错认继续。姚曦月发现对方真实身份后夺回账号，冒领女友身份。江牧野从声音、饮食习惯和相处感觉察觉不对，安排宿舍聚餐确认。与此同时，他的朋友也把姜灯灯认作自己的网恋对象，揭出姚曦月长期盗用室友照片同时经营多个账号。姜灯灯与江牧野当面对清误会，重新选择彼此；姚曦月的骗局败露，两位主角也在关系中逐步缓解社恐和失眠。
- 可复用机制：被别人丢弃的低价值对象其实拥有最高身份；长期单向分享先建立情感依赖；姓名、照片与声音三种身份信息错位；男主识破冒领靠日常习惯而非单看外貌。
- 使用边界：原文后段切换男主视角，并以调查、报警和司法处理收尾；新作只能保留“生活细节拆穿冒领”，不得沿用程序化办案结局。高额转账只是身份刻度，不能代替情感发展。

## 《反派泛泛爱》

- 平台：知乎
- 原型定位：豪门恶霸妹妹 × 表面清贫的失散继承人；弹幕、伪反派、双向暗恋
- 导语摘要：豪门龙凤胎自认是贵族学校里的反派，哥哥纠缠贫困校花，妹妹强追清冷学神。哥哥突然闯入阻止妹妹靠近学神，近乎恐惧地劝她换个人喜欢；被留下的学神却卸下隐忍，显露阴郁占有欲。
- 导语结构：用“邪恶双子星”快速贴人设 → 展示女主主动追人和男主表里反差 → 哥哥带着未来信息强行阻断 → 男主真实态度反转留下危险钩子。
- 故事梗概：许曜突然看见弹幕，得知自己和妹妹许霁会作为恶毒配角欺辱“男女主”，最终牵连家族遭到报复。他立刻停止追逐校花江羡宁，并强迫许霁转班、远离贫困学神周煦安。许霁不明原因，只看到周煦安与江羡宁在深夜亲密相处，又在雨夜撞见周煦安解决围堵者，遂相信哥哥对其危险性的判断。周煦安随后被神秘豪门认回，成为唯一继承人，并带走江羡宁。许霁以为两人相爱，周煦安却主动回来追问她为何失约和疏远，说明江羡宁是幼年一同失散的亲妹妹；他过去不回应许霁，是因尚无能力保护妹妹和喜欢的人。另一边，许曜被江羡宁逼问出弹幕真相，两人发现所谓男女主其实是兄妹，兄妹俩也从未真正霸凌他们，原剧情早已失效。四个人摆脱标签，两对感情都从单向追逐转为双向选择。
- 可复用机制：外部叙事把角色误标为反派，实际行为只是笨拙示爱；“他危险所以离开”与“他一直等她”形成情感反转；贫困学神后置揭晓顶级继承人身份；兄妹关系被误读成爱情关系。
- 使用边界：新作不能照搬弹幕、贵族学院、失散继承人和兄妹双情侣的整套组合；若用外部预言，必须让女主用自己的观察和选择推翻它，不能靠全知视角直接解释。

## 《再次见到你》

- 平台：知乎
- 原型定位：新人记者 × 顶流歌手；旧物寻人、同名误会、双向暗恋
- 导语摘要：女主买到一部二手旧手机，发现通讯录里存着自己高中号码，草稿箱还有大量未发送的少年告白。顶流男星随后悬赏寻找同款手机，卖家急着回购，女主决定越过中间人亲自领取高额奖金。
- 导语结构：异常旧物连接过去 → 草稿箱把普通交易升级为多年暗恋 → 顶流身份和高额悬赏抬高价值 → 女主主动联系失主，留下告白对象是谁的钩子。
- 故事梗概：林书言误买到顶流梁闻璟高中时的诺基亚，手机里保存着她的号码和写给“LIN SHU YAN”的大量未发送短信。因为同校还有一位拼音相同、后来成为演员的林舒颜，林书言认定梁闻璟喜欢的是校花，藏起自己高中三年的暗恋，只准备归还手机。她让舍友代为交还，梁闻璟却从手机新照片中认出她，询问她的近况。毕业后成为记者的林书言被安排采访梁闻璟的演唱会，两人再次见面；林舒颜利用同名误会默认绯闻，还私下贬低林书言。演唱会最后一场，梁闻璟公开澄清自己的暗恋对象是素人林书言：当年他为了被她采访才报名主持，又为了被她看见走上舞台。两人核对旧手机与少年往事，确认彼此曾长期暗恋。梁闻璟正式追求她，故事以他回答“今年最开心的是再次见到你”收束。
- 可复用机制：核心物件同时承担导语钩子、身份凭证和首尾回扣；同音姓名制造长期误判；公众认知与私人真相对撞；高位男主的职业成就源自想被普通女主看见。
- 使用边界：原文含男主独立视角和舆论录音翻盘，新作不得沿用；同名误会必须在读音、书写或称呼上有可信根源，不能只靠所有人不问全名。

## 《渺渺》

- 平台：知乎
- 原型定位：破产前富家主动型女主 × 清贵年长教授；青梅竹马、女追男、守护型爱情
- 导语摘要：女主误解教授课堂上的反诈玩笑，以为他穷到想吃软饭，直接拿饭卡去办公室包养他，承诺食堂牛肉煎饼随便吃。
- 导语结构：把严肃课堂话术故意按字面误读 → 女主立即执行荒唐追求 → 身份与资源反差颠倒传统霸总关系 → 男主如何接住“包养”的喜剧钩子。
- 故事梗概：江渺渺从小追逐比自己年长的顾准，家中暴富后更把两人的关系理解成“有钱女霸总包养清贵教授”。父亲把婚外所生的儿子带回家，又因经营问题令家业迅速崩塌，母亲离开霖州开始新生活，江渺渺从被宠爱的富家女变成可能受父亲旧事牵连的孤身学生。顾准辞去教职，借助家族与朋友的资源替她处理风险，把她带回顾家老宅过年；两人在高低床、年夜饭和互相试探中确认多年感情。顾准以为她天真、需要保护，江渺渺却早已主动切割父亲留下的麻烦，并在关系里持续掌握节奏。她接受了顾准的稳定与善意，也让克制守礼的顾准承认欲望和爱意。家庭风波结束后，两人结婚，开篇“谁吃谁的软饭”被改写为彼此接住对方的人生。
- 可复用机制：强势女主用金钱话术追求清贵男主；表层是老男人被调戏，深层是稳定型伴侣承接女主失去家庭后的不安全感；童年高低床和成年同住形成场景回扣。
- 使用边界：原文家庭主线高度依赖审计、案件、检察机关和设局抓捕，与现行硬约束冲突，只能学习感情关系和喜剧声线，不能召回其解决外部冲突的方式。

## 《贪心契约》

- 平台：知乎
- 原型定位：自由职业妻子 × 缺爱创业总裁；协议婚姻、先婚后爱、妻管严反差
- 导语摘要：女主误拨不熟的协议丈夫电话，恰逢男主和朋友赌谁的妻子先来电谁买单。她慌乱地催他回家，否则锁门；男主当众叫她老婆并答应立刻回去，一通错拨开始撕开假婚姻。
- 导语结构：协议夫妻的不熟先制造反常 → 偶然电话撞上带输赢的公共场合 → 女主临时扮演真妻子 → 高位男主欣然服从，承诺关系将被兑现。
- 故事梗概：司蕴与创业成功的霍璟珩协议结婚一年，分房生活、互不干涉。霍璟珩临时手术，司蕴第一次以妻子身份签字并照料他，收走手机、管住作息；从小被父母忽视的霍璟珩第一次体验到有人等他、管他，开始主动提前回家。司蕴误拨电话并随口设置门禁后，他认真遵守，她却因担心越界主动撤回关心。霍璟珩终于暴露情感缺口，低声请求她继续管自己，并提出废除协议、尝试真正的夫妻生活。两人在同住、晚宴照顾和吃醋中拉近距离。霍家父母为利益安排新的联姻对象，司蕴误以为自己仍会被替换而疏远；霍璟珩当面解释原生家庭创伤，拒绝家族控制，撕毁协议并正式求婚。此后他公开妻子身份，也主动报备行程，开篇的临时“妻管严”成为他甘愿拥有的家庭日常。
- 可复用机制：照顾生病只是触发器，真正关系引擎是高位男主对“被惦记、被约束”的渴望；错拨电话把私下关系公开化；女主撤回关心后，男主主动索取关系；协议实体在结尾被销毁，完成首尾兑现。
- 使用边界：避免把照顾写成流水账，也不能只靠原生家庭独白证明男主缺爱；需通过持续选择展示依赖。资产赠与仅能辅助承诺，不能充当感情高潮。
