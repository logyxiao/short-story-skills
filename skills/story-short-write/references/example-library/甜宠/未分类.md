# 未分类甜宠例文卡

## 《枝枝好运》

- 平台：未分类
- 原型定位：乐天女大学生 × 成熟集团总裁；冒充家属、实习近水楼台、年龄反差
- 导语摘要：女主低价买到高级自助名额，赴约后才知道卖家让她冒充公司团建家属。她混进一群精英中吃得正欢，被要求向英俊老板敬酒，却把“施总”叫成“史总”，让全桌陷入尴尬。
- 导语结构：低价占便宜的日常欲望 → 冒充家属闯入高阶社交场 → 又帅又有钱的核心男性出场 → 谐音社死把身份暴露风险推到最高。
- 故事梗概：大学生蓝枝枝在二手平台购买自助名额，被员工孙浩假装成妹妹带进施氏团建，因叫错老板施骁的姓氏，临场谎称自己仰慕他才来，反而留下深刻印象。施骁送她回校，随后在导师陈屿办公室撞见她，冒充家属的谎言当场拆穿；陈屿顺势把她送到施氏实习。蓝枝枝用“老板心情天气表”、偷坐总裁椅等社死日常拉近距离，又在同事拿走方案后凭真正能力完成更出色的现场展示，让施骁从觉得有趣转为欣赏。年轻男实习生接近她后，施骁显露年龄焦虑和占有欲，并以临时见客户为由带她去海岛，坦白自己早已被她的生命力与能力吸引。蓝枝枝识破假公差，主动回应心意。两人确定关系后回到学校，导师发现学生被好友追走，喜剧冲突完成收束。
- 可复用机制：小额交易把普通女主送入顶级资源场；女主先靠社死反差被看见，再靠现场能力获得尊重；成熟男主面对同龄竞争者产生年龄不自信；导语里的“冒牌家属”最终兑现为真实伴侣。
- 使用边界：原文存在多次离开女主的视角切换；新作只保留女主能观察到的吃醋和偏爱。不能用豪车、海岛和职位碾压替代女主自身闪光点。
