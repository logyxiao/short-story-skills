# 题材风格包：甜宠

> 适用：番茄短篇、知乎/盐言故事及相近通俗恋爱短篇。先执行 `short-craft.md` 通用规则；涉及平台形态时再叠加 `submission-craft.md`。本包只负责甜宠的关系结构、糖点机制和风险分流。

## 题材定义

甜宠不是“全程没有冲突”，也不是“有钱男主送礼，最后结婚”。它的核心是：

> **一个具体的人被看见、被回应、被允许靠近，并在持续行动中确认自己不是可替代项。**

读者主要获得四种满足：

1. **识别感**：对方认得真实的我，而不是照片、马甲、身份或功能。
2. **例外感**：同一套规则到了我这里，发生有意义的变化。
3. **安全感**：我能表达需要、拒绝和不安，关系不会立刻崩塌。
4. **共同生活感**：两人不只完成告白，还长出可持续的新日常。

甜宠可以包含身份错位、协议婚姻、暗恋、创伤、家庭危机和奇幻规则。冲突用于检验关系，不用于无限消耗一方来抬高另一方。

默认输出为双方自由选择的 HE。若导言真正承诺的是“拒绝所有追求者、找回自己”，应分流为**反恋爱成长型**，不要强塞 CP。暗黑强制爱可以作为幻想子类，但必须显式标注，不能伪装成默认健康甜宠。

## 语料校准

本包依据 `例文/甜宠` 下 44 篇文本逐篇审读后重构，覆盖 8 篇番茄、30 篇盐言、5 篇知乎及 1 篇未分类文本。审读维度包括导语承诺、分节结构、关系引擎、甜度机制、高潮答案、结尾形态和边界风险。

全量语料推翻或修正了几条过度绝对的旧规则：

- 甜宠不只有“误会—反转—告白”。纯日常可以靠安全感、私人空间和共同生活推进。
- 身份错位常不止一层；账号、照片、真名、线下身份和读者认知可能同时错位。
- 长误会并非天然失败。失败的是只靠重复沉默续命；有效长误会会生成新证据、新行动和关系后果。
- 高成本牺牲不是每篇必需。稳定回应、尊重边界也能完成高潮；只有前文提出现实阻力，才需要匹配的现实选择。
- 传统反转不是硬指标。公开选择、主动奔赴、关系重新命名、恢复自主生活都可成为高潮。
- 样本中存在跟踪、冒名、权力差、药物、囚禁和强制亲密。它们是**语料现象**，不是默认推荐规范。

不得照搬例文的人物、桥段组合、专有设定或句子，只抽取结构功能和关系机制。

## 人设幻想配置

全量语料中，高频男主不是朴素现实型“普通好人”，而是**外形、资源和社会能力都明显高于平均值的强幻想角色**：总裁/老板、豪门继承人、顶流明星、权臣、贵族少爷、高岭校草、教授或其他行业顶尖者反复出现。其吸引力不只来自有钱，更来自“他本来拥有很多选择，却只对主角破例”。

因此，用户只说“甜宠”“知乎风甜宠”而没有要求现实主义时，默认优先使用高幻想配置，不要擅自降成两个普通职业者处理生活难题。现实职业线可以保留，但它应服务人物光环、能力高光和资源反差。

### 男主人设三层

1. **外显光环**：神颜、财富/家世、社会地位、专业能力至少命中两项，知乎与盐言默认优先三项并存。
2. **私人缺口**：失眠、情感表达障碍、家庭疏离、高需求、被利用恐惧、身份压力等，让他不是无缝的奖品。
3. **女主专属反差**：人前冷淡强势，人后黏人、顺从、吃醋、报备、做饭、低头或主动交出关系权限。反差必须被具体场景反复证明。

高资源男主常用落点：

- 总裁/继承人：控制公司、项目和财富，但在女主面前主动接受管束或修改既有规则。
- 顶流/公众人物：拥有万人关注，却能从声音、旧物、用词和习惯中认出一个素人，并承担公开选择的舆论成本。
- 高岭校草/学神：外貌与能力形成校园稀缺性，私下暴露笨拙、黏人或占有欲。
- 教授/行业大牛：专业话语权强，恋爱中却被女主的直球、误读或生活能力打乱秩序；涉及师生关系时避开直接考核权。
- 豪门少爷/权势角色：资源可放大保护与承诺，但家庭、继承或阶层必须成为可见阻力，不能只贴一个“有钱”标签。

### 女主人设不能只是“普通”

女主即使家境普通，也必须有一种不可替代性：

- 稀缺能力：创作、专业判断、解决危机、照顾具体生活而非泛化“善良”。
- 鲜明性格：直球、财迷、女王、社恐但会表达、嘴硬心软、清醒逐利等。
- 隐藏反差：看似傻白甜实则会设局，看似拜金实则边界清楚，看似软弱却在关键处主动退出。
- 情绪价值：能听懂男主没说出口的需求，但不是无底线哄人或治疗工具。

女主可以是素人、学生、实习生、小职员、落魄千金，也可以同样富有强势。决定吸引力的不是职位高低，而是她具备男主用钱和权都无法批量购买的特质。

### 幻想感的可见证据

不要只写“他很帅、他很有钱”。至少选两类证据进入情节：

| 幻想维度 | 可见写法 |
|---|---|
| 外貌稀缺 | 路人认出、公开场合视线集中、镜头/照片传播，但控制次数 |
| 财富资源 | 具体住所、股份、转账、项目、律师/医疗/舆论资源，以及使用资源后的现实后果 |
| 社会地位 | 下属和同行反应、公开决策权、职业成绩，不靠旁白报履历 |
| 专属偏爱 | 同一规则对别人有效，对女主主动改；记住她的细节胜过认脸 |
| 低位反差 | 高位者先发消息、等回复、学做饭、承认吃醋、请求继续被管 |
| 公开选择 | 在家族、公司、镜头或利益面前确认关系并承担代价 |

资源爽点要与感情证据绑定。送房、转股份、高额转账能放大“被选择”，但不能替代认人、倾听、道歉和重新同意。

### 平台默认选角

- **知乎/盐言**：优先“神颜高资源男主 × 有职业能力或身份秘密的女主”，用社会距离制造信息差，用公开选择完成高潮。
- **番茄**：可进一步放大总裁、少爷、人外血统和极端反差，先把萌点与身份标签直给。
- **现实向指定**：用户明确要求普通人、烟火气或去豪门化时，才把主要幻想转移到稳定回应和共同生活。

选角完成后自问：若删掉姓名和“总裁/校草”标签，这个人是否仍能通过资源调用、他人反应、说话方式和女主专属反差被认出来？不能，就说明只是空标签。

## 实际工作流

用户给出“导言 + 甜宠要求”时，按以下顺序执行：

1. **锁定导言承诺**：保留用户给出的事实、关系、关键台词和结局要求。
2. **配置幻想人设**：未指定现实向时，先给核心角色配置可见的外貌、资源/能力光环和女主专属反差。
3. **制作承诺卡**：提取关系起点、异常事件、信息差、读者追问和风险边界。
4. **选择一个主结构**：从结构路由中选一个，最多叠加一个副结构。
5. **建立关系状态表**：明确双方能做什么、不能做什么、分别知道什么。
6. **排情节节点**：每 1—2 节至少改变一项关系状态；纯日常可改变生活融合度而非冲突烈度。
7. **设计高潮答案**：高潮直接回答导言提出的问题，不用通用告白代替。
8. **执行风险分流**：健康甜宠、灰度关系、暗黑强制爱使用不同边界。
9. **平台调校**：按目标平台调整信息密度、篇幅和声音。
10. **写作与验收**：检查信息、关系、糖点、修复和收尾。

用户没有提供导言时，才生成新导言：

```text
关系起点 + 反常事件 + 一句关系失衡台词 + 一个尚未回答的问题
```

不要先写同义简介，再在第 1 节原样重讲。导言已经发生的事件，第 1 节应继续写后果、补充新信息或改变选择。

## 导言承诺卡

扩写前写入 `设定.md` 或大纲头部：

| 字段 | 判断问题 |
|---|---|
| 不可改事实 | 用户明确给出的身份、事件、台词、规则和结局是什么？ |
| 关系起点 | 陌生人、朋友、上下级、雇佣、协议伴侣、家人式陪伴、真情侣还是前任？ |
| 反常事件 | 导言中最违反常识、最想让人追读的动作或信息是什么？ |
| 表层问题 | 读者最直接想知道什么？例如“网恋对象是谁”。 |
| 深层问题 | 关系真正要回答什么？例如“知道真实身份后还会不会选我”。 |
| 信息持有者 | A、B、读者、第三方分别知道什么？ |
| 情感需求 | 双方各自想获得什么：被选择、被照顾、自由、家、未来？ |
| 持续同框 | 什么让两人自然持续相处，而不是连续偶遇？ |
| 首次兑现 | 导言后的前两节先交付哪一小块甜或真相？ |
| 禁区 | 用户禁止什么；哪些伤害不能被写成宠？ |

处理结果分三层：

- **硬约束**：原样保留含义，只做文字精修。
- **可优化项**：可调整信息顺序、视角、物件和钩子位置。
- **待补项**：补双方欲望、持续同框、升级节点、高潮答案和新日常。

若导言与默认健康甜宠冲突，不要悄悄篡改。先判断用户要的是降低伤害、明确写成灰度/暗黑幻想，还是拒绝关系并完成自我成长。

## 身份信息矩阵

身份类故事必须先做矩阵，避免作者自己混淆“爱的是谁”。

```text
身份层：账号名 / 照片 / 真名 / 线下身份 / 家庭身份 / 隐藏设定
A 认为 B 是谁：
B 认为 A 是谁：
读者当前认为：
第三方制造了什么错误：
本节新增证据：
证据被如何误读：
揭晓后需要重新确认什么：
```

身份揭晓只完成“知道真相”，不自动完成关系修复。若此前有冒名、隐瞒或欺骗，还要写：说明动机、承认影响、归还选择权、重新作出关系决定。

## 主结构路由

先选主结构，再选具体糖点。主结构最多叠加一个副结构；超过两个时，删掉不能改变关系的马甲、系统或身世。

### A. 纯日常升温型

**信号**：同居、邻居、同桌、一起学习、共同养宠、连续聊天，无强外部阴谋。

```text
反常相处规则 → 小需要得到回应 → 私人空间开放 → 共同习惯形成
→ 短暂缺席暴露依赖 → 双方给关系命名 → 新日常
```

此型不强制反派、牺牲或大反转。高潮可以是一次主动留下、一次回家或一次双向准备好的承诺。

### B. 身份错位 / 网恋型

**核心问题**：身份变化后，爱是否仍指向这个具体的人。

```text
错误身份建立亲密 → 线下出现同步细节 → 可验证反证
→ 一方先识破并选择处理方式 → 身份揭晓造成选择危机
→ 处理欺骗与边界 → 以真实身份重新确认
```

不要连续“差一点认出”却无后果。每次延迟至少新增一条证据、一个选择、一次风险或一项关系权限。

### C. 协议 / 交易 / 名分先行型

**核心问题**：照顾究竟是履约、利益交换，还是双方自愿关系。

```text
明确合同边界 → 第一次超出义务 → 双方不同解释
→ 日常规则被主动修改 → 旧协议造成真实退缩
→ 公开废止或重签规则 → 可持续的新约定
```

金钱可以启动关系，不能替代情感确认。资源差明显时，弱势方必须可拒绝、可退出且不受报复。

### D. 暗恋回响型

**信号**：旧手机、信件、留言簿、照片、匿名照料、多年重逢。

```text
旧物出现 → 误认旧物指向 → 当下互动重复旧细节
→ 多件证据互证 → 暗恋者视角补齐盲区
→ 当面确认今天的选择 → 旧物获得新用途
```

旧物至少承担两次功能：第一次制造谜题，第二次证明选择。结尾突然拿出情书不算伏笔回收。

### E. 家庭归属 / 关系重新命名型

**信号**：被收养、真假少爷、长期当家人、害怕失去“家”。

```text
建立可靠家庭位置 → 生活照料与归属加深 → 成年后的排他性显影
→ 双方辨认关系性质 → 处理家庭身份、伦理与退出风险
→ 重新命名 → 保留家感并建立平等伴侣关系
```

不能用“不是亲生”跳过伦理与权力问题。若一方曾承担监护、资助或事实抚养角色，应优先分流。

### F. 双向救赎 / 自主恢复型

**信号**：创伤、残障、失眠、社恐、抑郁、家庭危机、被孤立。

```text
尊重边界与现实处境 → 用具体劳动减少生活障碍 → 被帮助者保留决定权
→ 双方各自暴露脆弱 → 各自完成一次主动支持
→ 专业治疗/现实问题继续 → 关系成为支持系统之一
```

爱情可以陪伴康复，不能宣称治愈精神疾病、残障或创伤。

### G. 设定反差 / 不可靠叙述型

**信号**：人外、穿书、弹幕、系统、失忆、世界规则。

```text
直给外部规则 → 角色据此选择 → 现场行为出现反证
→ 多次反证产生新因果 → 角色亲自交叉核对
→ 推翻或重新定义规则 → 设定专属日常
```

弹幕、系统和旁白可以撒谎。最终判断落到人物持续行动，不用另一套全知解释强行盖章。

### H. 双线群像型

适用于双胞胎、兄妹/姐妹双 CP、四人共同危机。要求：

- 两条线共享一个核心命题或同一倒计时。
- 至少两个节点让一条关系的选择改变另一条关系。
- 使用镜像但不复制：同一需求用不同性格表达。
- 高潮分别回答两条关系问题，不能只给主 CP 完整闭环。

### I. 反恋爱成长型

```text
恋爱骗局或错误关系 → 主角识别模式 → 伤害者悔悟或换人诱惑
→ 新候选人的问题也被验证 → 拒绝回收 → 事业、友情或自我生活落点
```

此型可以无 CP、无婚恋 HE。完成的是自我选择，不应被验收误判为不合格。

### J. 暗黑强制爱型

包含囚禁、药物、强制生育、跟踪监控、伤害威胁、不可退出占有时，必须独立标注：

- 区分角色的欲望解释与文本的事实判断。
- 不用“后来爱上了”追溯性抹除当时的拒绝。
- 不把醉酒、沉默、依赖、经济困境或身体反应当作同意。
- 若目标是健康 HE，必须写停止伤害、恢复自由、承担后果和重新建立关系；做不到就不要包装成健康互宠。

## 关系状态：不要机械爬梯

排大纲时追踪五个维度：

| 维度 | 可观察变化 |
|---|---|
| 识别 | 只认身份 → 记住习惯 → 理解真实需要 → 接受完整自我 |
| 信任 | 防备 → 允许帮助 → 分享秘密 → 共同决策 |
| 权限 | 必要接触 → 私人空间 → 情绪照料 → 身体/未来权限 |
| 公开 | 隐藏 → 小圈承认 → 面对现实站队 → 稳定社会身份 |
| 生活融合 | 偶遇 → 固定相处 → 共同习惯 → 共同计划与家 |

每节大纲附加：

```text
关系状态（前→后） | 新证据 | 本节甜点 | 谁主动 | 边界/代价 | 节尾悬念 | 下一节兑现
```

有效推进包括：一个维度前进、错误认知被纠正、主动权转移、共同生活出现不可逆痕迹，或风险暴露后重新协商边界。连续两节若无新信息、无关系变化、无生活融合、无情绪后果，应合并或删除。

## 糖点设计

有效糖点不是“他宠溺地笑了”，而是：

```text
具体识别 + 针对性回应 + 关系后果
```

例如：记得对方忌口，调整一桌菜，使对方第一次愿意同桌；知道对方怕被丢下，主动说明行程，建立报备而非查岗；发现轮椅不适，先询问再调整，让对方主动扩大生活半径；旧账号断更后第一次主动询问，使单向树洞变成双向对话。

优先使用六类糖：

1. **识别糖**：声音、习惯、用词、食物偏好让身份不可替代。
2. **响应糖**：提出需要后得到稳定回应；重点是“叫我就来”，不是无理由神兵天降。
3. **自主糖**：尊重拒绝、归还选择权、协助而不代替决定。
4. **共同生活糖**：拖鞋、冰箱贴、发绳、杯子、宠物、饭菜等空间痕迹增加。
5. **公开选择糖**：在现实压力前澄清关系，承担名誉或利益后果。
6. **对称糖**：前段 A 照顾 B，后段 B 用自己的方式回应 A。

小礼物和脸红可以重复，但功能不能重复。同一物件最好经历：出现 → 被误读 → 被认领 → 获得新用途。

### “高代价”何时需要

- 只问“会不会习惯彼此”：稳定出席和共同日常即可。
- 问“身份曝光后是否还选我”：用真实身份重新确认。
- 问“家族/利益面前站谁”：需要公开选择及现实成本。
- 问“伤害能否修复”：需要停止、道歉、补救和重新同意，口头告白不够。

## 误会与信息差

误会不设机械“两节上限”。判断是否还能继续：

1. 是否出现新证据？
2. 角色是否因此做了不同选择？
3. 是否改变关系，而非只继续沉默？
4. 最终揭晓能否逐条回收前文细节？

四项都否，就应尽快解开。身份风险、职业伦理、家人安全、世界规则可构成有效延迟；反复听半句话、拒绝问一句即可解决、第三方总在关键时刻打断，属于无效拖延。

揭晓后的修复流程：

```text
事实揭晓 → 情绪反应 → 责任判断 → 选择权归还 → 新行动 → 重新确认
```

## 高潮设计

| 导言深层问题 | 合格高潮 |
|---|---|
| 他爱的是账号、照片还是我？ | 用真实相处证据认出，并以真实身份重选 |
| 协议之外有没有真心？ | 明确废止旧规则，建立新规则并承担现实后果 |
| 他是否早就喜欢我？ | 旧物和当下行为互证，今天再主动确认 |
| 我会不会再次被抛下？ | 稳定出席、共同计划和可执行承诺，而非一句永远 |
| 世界说我是反派怎么办？ | 人物用持续行动推翻外部叙述 |
| 这段伤害能否变成爱情？ | 先停止和承担，再谈是否重新开始 |

高潮后至少展示一个“确认关系后才能出现的新生活”。婚礼、领证、怀孕只能是结果，不是问题的答案。

## 人物与叙述

- 第一人称适合强导语、吐槽和认知错位；内心声音必须稳定，不能为误会突然降智。
- 心动瞬间放慢，日常过场压缩；重创伤段降低玩梗密度。
- 男主不必永远“台词少而金贵”。黏人小狗、话痨反差和双视角可以大量表达，但说话方式要有角色来源。
- 一段对话至少暴露欲望、试探边界、纠正认知、改变权限或形成两人专属话术中的一项。
- 不要连续用金句互砸。可信度常来自笨拙、停顿、答非所问和事后补充。

叙事装置的使用：

- **弹幕/系统**：允许不可靠，但必须埋现场反证。
- **聊天记录**：每次出现要改变信息或关系，不能只做排版灌水。
- **男主视角番外**：只能补动机和盲区，不得推翻主线事实。
- **萌娃/宠物**：应有自身欲望和行动，不只负责助攻。
- **第三者/情敌**：触发表达即可，不能承担全部沟通，也不要靠彻底污名化女性换糖。

## 风险分级

### 一级：默认健康甜宠

双方可退出；拒绝有效；隐私受尊重；关系不影响基本生存；冲突后仍可自由离开。可直接使用协商式同居、短时吃醋、身份误会、公开选择和双向陪伴。

### 二级：灰度关系

老板员工、师生边缘、资助与受助、巨额转账、协议婚姻等强资源差，必须补齐：

- 非直接考核或雇佣报复；
- 弱势方可拒绝、可离职、可保留独立资源；
- 关系确认发生在重新协商之后；
- 财富和权势不替代道歉与倾听。

### 三级：暗黑幻想

囚禁、药物、强制生育、死亡威胁、跟踪定位、醉酒或失去能力时亲密、以自伤逼回应，不得用以下说法洗白：

- “身体有反应，所以愿意。”
- “后来爱上了，所以以前不算强迫。”
- “他是病娇/人外，所以不懂边界。”
- “占有欲强，说明爱得深。”

若用户要普通甜宠，应降级或删除真实伤害；若明确要暗黑强制爱，保留危险性并准确标注。

### 专项边界

- **精神健康/残障**：爱人不是医生；优先写自主、无障碍、专业支持和长期恢复。
- **隐私**：查航班、监控、定位、买手机号、擅入住宅都需要授权范围；一句“随便”不等于无限许可。
- **同意**：亲吻、身体接触、角色扮演和性行为分别确认；同意一次不等于永久同意，可随时撤回。
- **吃醋**：可以暴露不安，不能升级成限制社交、掐脖、砸手机和威胁第三者后仍被当糖。
- **救赎**：阶段性付出可不对等，但另一方必须保有主体性和回应能力。
- **家庭归属**：恋人可以是支持系统，不能成为唯一人际关系和全部生存意义。

## 节奏与平台

- 导言后前两节交付一小块承诺：反证、破例或身份线索。
- 每 1—2 节至少发生一次有效关系变化。
- 轻甜段可低烈度；心动瞬间短暂升高后回落。
- 重创伤故事允许较长现实主线，但关系必须参与解决问题。
- 章尾优先留“悬糖”：未完成确认、新露旧物、超出边界的行动或改变认知的一句话。
- 下一节先兑现上一节一部分，再建立新期待；不要连续只差一点揭晓。

| 平台 | 开篇 | 中段 | 高潮/收尾 |
|---|---|---|---|
| 番茄短篇 | 人设、目标和反差直给，尽快同框 | 高频轻喜互动，设定萌点反复使用 | 确认直接，常用时间跳转或番外补共同生活 |
| 盐言 | 高概念导语，身份错位、弹幕或任务感强 | 分节密、翻牌多；成人向与灰度设定需标风险 | 细节集中回收，常用身份揭晓、公开选择或视角番外 |
| 知乎故事 | 可容纳较长前史、职业线和家庭现实 | 物件证据、现实事件与关系并进 | 重因果解释和生活落点，不必都靠大反转 |

目录标签只是初始参考；若文本形态与目录名不一致，以实际文本和用户目标为准。

## 常用结构公式

- **纯日常**：反常相处 → 需求回应 → 空间开放 → 共同习惯 → 缺席显影 → 关系命名 → 新日常。
- **身份错位**：错误身份亲密 → 线下反证 → 证据升级 → 一方识破 → 真相危机 → 修复 → 真实身份重选。
- **协议关系**：规则先行 → 超额照料 → 修改日常 → 旧协议反噬 → 正式废止/重签 → 共同生活。
- **暗恋回响**：旧物 → 指向误读 → 当下复现 → 证据互证 → 今日确认 → 旧物新用途。
- **家庭归属**：获得位置 → 共同生活 → 排他性显影 → 关系辨认 → 伦理处理 → 重新命名。
- **双向救赎**：尊重边界 → 具体改善 → 双方示弱 → 各自支持 → 现实问题继续 → 稳定支持网。
- **不可靠叙述**：外部结论 → 角色相信 → 现场反证 → 交叉核对 → 推翻规则 → 自主选择。
- **双线群像**：镜像起点 → 交叉影响 → 共同危机 → 分别回答 → 共享未来。
- **反恋爱成长**：骗局 → 识别模式 → 拒绝回收 → 新诱惑再验证 → 事业/友情/自我落点。

## 甜宠专项验收

### 导言与结构

- [ ] 第 1 节继续导言后果，没有换一套开头重讲。
- [ ] 表层问题和深层问题都已写明。
- [ ] 选择一个主结构，副结构不超过一个。
- [ ] 高潮直接回答导言问题，而非套用通用告白。
- [ ] 无传统反转时，关系升级或生活融合足以支撑高潮。

### 信息与误会

- [ ] 身份故事列清账号、照片、真名和线下身份。
- [ ] 每次延迟揭晓都带来新证据、新行动或新后果。
- [ ] 真相没有自动洗掉欺骗和伤害。
- [ ] 男主视角或番外没有推翻主线事实。

### 关系推进

- [ ] 每 1—2 节至少改变一项关系状态。
- [ ] 双方都有主动靠近、表达需要和作出选择的节点。
- [ ] 糖点包含具体识别、针对回应和关系后果。
- [ ] 纯日常不被强塞牺牲；现实阻力有匹配的现实选择。
- [ ] 共同生活痕迹逐渐增加，而非只靠口头宣布很甜。

### 边界与修复

- [ ] 已判断默认、灰度或暗黑等级，并使用对应写法。
- [ ] 拒绝、沉默、醉酒、依赖和身体反应没有被当作同意。
- [ ] 权力差关系中，弱势方拥有真实退出路径。
- [ ] 精神健康、残障和创伤没有被爱情直接治愈。
- [ ] 造成伤害后，写了停止、责任、补救和重新选择。

### 结尾

- [ ] HE 来自双方自由选择；反恋爱成长型则完成自我选择。
- [ ] 核心障碍已解决，不用婚礼、怀孕或财富盖住问题。
- [ ] 展示至少一个关系确认后才可能出现的新日常。
- [ ] 回收导言、贯穿物件或重复话术中的至少一项。

## 与去 AI 规则协调

甜宠可保留第一人称吐槽、网络语、聊天记录、心动微反应和角色化重复称呼；它们是类型声音，不应机械删除。

仍要避免：

- 用“嘴角微扬、眼底闪过、宠溺一笑”批量代替反应；
- 每次心动都只写耳红、心跳漏拍；
- 旁白宣布“他很宠我”，却无具体行动；
- 为追求金句让所有人说同一种腔调；
- 用治愈宣言跳过现实过程；
- 高频梗破坏创伤、法律、医疗和边界场景的可信度。

落到正文后，再按 `short-craft.md` 和 `story-deslop` 要求处理句式、标点、重复和模板味。
