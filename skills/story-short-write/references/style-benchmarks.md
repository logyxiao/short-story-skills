# 古言 / 现言主文风参考

本文件把用户指定例文提炼成可执行的文风卡。参考的是叙述距离、段落节奏、对话声线和信息组织，不复制原句、人名、专有设定或关键桥段。题材包决定故事机制，本文件决定古言 / 现言的基础声音；两者冲突时，正文格式与去 AI 味规则优先。

## 使用顺序

1. 先判断时代：古言、现言；没有时代信号时默认现言。年代文、民国文或跨时代题材优先遵从用户指定，未指定时选更接近的卡并在导语候选前用一句话说明。
2. 每个新项目第一次生成导语候选前，完整读取对应主参考原文一次，结合下方文风卡形成项目文风指纹。后续改导语、改设定或续写正文复用该指纹，不反复通读原文。
3. 导语选定后，把“时代文风、主参考路径、采用特征、明确不采用项”写入 `设定.md` 的“文风档案”。
4. 主参考文件不可读时，说明一次，并使用本文件的派生文风卡继续；不要因此越过当前审批阶段。

## 古言主参考：《卿候海棠》

- 路径：`/Users/to/Documents/小说工作台/例文/古言/浮月/卿候海棠.txt`
- 定位：古言短篇的基础叙述声音，不等于限定重生、宫廷或三角关系题材。

### 应采用

- 第一人称贴身叙述，先写人物当下判断和反应，再补必要前情。
- 半白话表达：叙述清楚易读，古意主要由身份称谓、礼法、婚嫁、宫廷或家族秩序自然显出，不堆文言虚词和辞藻。
- 段落短，叙述与对话交替；一段通常只承担一个动作、判断或新信息。
- 对话承担关系权力和误会翻牌。身份越高，说话越短；女主内心声可直白、带一点天真或自嘲，形成轻巧反差。
- 回忆不单独写成长篇说明，而由眼前人物、旧话或具体选择触发，快速交代后立即回到当下。
- 小节结尾落在问题、身份暴露、反常动作或关系改判上，让下一节有明确承接。
- 环境只取能承载身份、危险或情绪的少量物件，不写大段亭台花木陈列。

### 不采用

- 不照搬例文的重生关系、皇室人物、姐妹替换、赐婚或结局处理。
- 不继承原文的逗号格式、省略号、错别字和偶发重复；统一服从 `short-format.md` 与 `short-deslop.md`。
- 不为了“古风”把现代白话逐词替换成生硬文言，也不让所有角色使用同一种宫廷腔。

## 现言主参考：《白沅》

- 路径：`/Users/to/Documents/小说工作台/例文/追妻追夫/知乎/白沅.txt`
- 定位：知乎感现言短篇的基础叙述声音，不限定网恋、校园、追妻或真假照片题材。

### 应采用

- 第一人称强口语，像当事人在复盘一件刚发生的离谱事；判断直接，少用作者式总结。
- 开篇迅速交代异常事件、误会核心和情绪落差，不从职业履历、家庭背景或环境介绍起笔。
- 手机消息、帖子、群聊、评论区、热搜等可以直接成为剧情现场，但每次出现都要带来新证据、误判或关系变化。
- 短段快切，叙述、聊天文本与当面对话交替；用生活化吐槽卸压，再立刻接下一次冲突。
- 现代细节要具体：平台、时间、金额、物品、校园 / 职场流程承担真实感，避免抽象地说“他很有钱”“她很漂亮”。
- 高幻想人物通过他人反应、资源使用方式、社交圈和选择成本显形；颜值、财富与地位服务关系张力，不写成资产清单。
- 误会依靠信息差逐层翻牌，读者每隔一两个小节得到一个新事实；关键对话短、带态度，不替角色解释完全部心理。
- 小节结尾优先落在新消息、认错人、被拉出黑名单、现场撞见或一句回旋镖上。

### 不采用

- 不照搬例文的网恋报复、照片冒领、过敏陷害、人物关系或游戏梗。
- 不继承原文的网络错字、标点混用、编号重复和偶发视角跳转；统一服从项目格式。
- 不为“知乎感”强塞帖子、群聊或热搜。没有证据与关系功能时，正常场景比网络界面更有效。

## 时代与题材的组合

| 时代 | 基础声音 | 再叠加 |
|---|---|---|
| 古言甜宠 / 宅斗 / 古代追妻 | 《卿候海棠》文风卡 | 对应 `genre-styles/` 题材包的关系引擎、情绪强度与收尾 |
| 现言甜宠 / 豪门 / 现代追妻 | 《白沅》文风卡 | 对应题材包的高幻想配置、身份差、爽点或火葬场结构 |
| 年代 / 民国 / 架空混合 | 由用户指定更接近哪套 | 只迁移叙述节奏，不强行迁移时代词汇 |

## 项目文风档案模板

写入 `设定.md`：

```markdown
## 文风档案

- 时代：古言 / 现言
- 主文风参考：{路径}
- 本篇采用：{3-5 条与本故事直接相关的语言和节奏特征}
- 本篇不采用：{例文的具体桥段、人物、专名及不符合项目格式的写法}
- 角色声线：{主角、关键角色各一句}
```
